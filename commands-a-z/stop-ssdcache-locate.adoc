= SSD 캐시 찾기 중지 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
'top ssdCache locate' 명령은 'start ssdCache locate' 명령으로 설정된 솔리드 스테이트 디스크(SSD)의 표시등을 끕니다.



[[supported-arrays]]
== 지원되는 어레이

이 명령은 모든 SMcli 패키지가 설치되어 있는 한 E4000, E2700, E5600, E2800, E5700, EF600, EF300, EF50 및 EF80 어레이를 포함한 모든 개별 스토리지 어레이에 적용됩니다.



[[roles]]
== 역할

E4000, E2800, E5700, EF600, EF300, EF50 또는 EF80 스토리지 어레이에서 이 명령을 실행하려면 Support Admin 역할이 있어야 합니다.



[[syntax]]
== 구문

[source, cli]
----
stop ssdCache locate
----


[[parameters]]
== 매개 변수

없음.



[[minimum-firmware-level]]
== 최소 펌웨어 레벨입니다

7.84

11.80은 EF600 및 EF300 어레이 지원을 추가합니다
